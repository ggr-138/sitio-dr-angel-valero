# Sitio web · Dr. Ángel Gerardo González Valero

Landing page del Dr. Ángel Gerardo González Valero, otorrinolaringólogo y cirujano de cabeza y cuello en San Luis Potosí.

## Estructura
- `site/index.html`: página principal
- `site/privacidad.html`: aviso de privacidad (borrador, pendiente de revisión legal)
- `site/styles.css` y `site/main.js`: estilos y animaciones
- `site/assets/`: fotos y pictogramas del logo

## Ver en local
```bash
npx http-server site -p 5173
```
Después abre http://localhost:5173
